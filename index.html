A customer support chatbot that speaks three languages

This assistant answers the most common questions of a bike shop: opening hours, delivery, returns, repairs, payment and order tracking. It recognises English, French and Albanian, tolerates typos, and hands the conversation to a human when needed.

Try it

How it works

  1. Normalise the message: lowercase, accents removed (é, ë, ç).
  2. Detect the language from frequent small words and known keywords.
  3. Score each intent against its keywords, with typo tolerance (Levenshtein distance).
  4. Answer in the customer's language, or ask for an order number, or hand off to a human.

Plain HTML, CSS and JavaScript (ES modules) · no framework · runs fully in the browser · source code
